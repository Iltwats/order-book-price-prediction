### A. Measure the gradient lost at 256 rows

For each sequence, use four fixed 256-row supervised suffixes ending at rows **4096, 8192, 16384 and 19456**, with endpoints interpreted as exclusive. Compare backward histories of **256 and 1,024 rows** ending at each same endpoint. For the longer history, set the first 768 rows' upstream coefficients to zero; both calculations therefore differentiate exactly the same supervised suffix and coefficient values.

Start each calculation from the current student's detached ORT upper state immediately before its window; consume unchanged ORT lower states. Apply the existing hidden/output forward corrections. Differentiate the upper GRU and head without any optimizer update. This produces **32 paired gradient comparisons**. Head gradients should agree within the prescribed gradient tolerances because their inputs and supervised suffix are identical; larger disagreement exposes an implementation error.

Report, globally and for each upper parameter tensor, gradient cosine similarity and `||g1024-g256|| / (||g1024|| + 1e-12)`, together with both absolute norms. Record zero norms explicitly; a zero short gradient with nonzero long gradient must not be discarded. Inspect raw local hidden/output errors before value correction. Require the existing numerical magnitudes and the existing FP32/FP64 gradient tolerances on the longer path; the accepted 256-row bridge does not automatically cover 1,024 rows. Preserve any failure instead of relaxing its threshold.

A prospective engineering trigger is a missing-gradient fraction above 20% in at least half the nonzero probes. This is a reason to test a longer window, not a statistical accuracy guarantee. Uniformly small differences, such as below 5% with cosine above 0.99, would weaken this explanation.

### B. Independently measure lower-layer potential

On the same four supervised suffixes, keep the backward history at **256 rows** and allow derivatives through both GRUs. Initialize both from their detached ORT prior states. Construct a lower-state forward correction before feeding the upper GRU, so its input values stay exactly ORT values while gradients can reach lower parameters. Preserve exact upper/readout forward corrections and the identical coefficient vector.

Do not reuse the frozen trainer's detached lower input and mistake its zero gradient for evidence. This new derivative path needs its own raw lower/upper numerical checks and FP32/FP64 VJP comparison. No weight is updated or exported as a candidate.

Report lower input-matrix, recurrent-matrix and bias gradients separately. Compare layer sensitivity using `||gradient|| × ||parameters||`, the first-order loss sensitivity to an equal relative L2 parameter displacement, alongside raw norms. This comparison is parameterization-dependent and measures local training potential only. Repeatedly substantial lower sensitivity with small result A differences would favor lower-layer adaptation over longer upper windows. Large values in both tests leave both explanations open.
